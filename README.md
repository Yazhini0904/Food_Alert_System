Overview

The Expired-Soon Food Alert System is a web-based application developed to reduce food wastage by helping users track and manage food items efficiently. It allows users to store details such as food name, category, quantity, purchase date, and expiry date. The system automatically monitors expiry dates and sends alerts when items are about to expire.

Objective

The main objective of this project is to minimize food wastage by providing an efficient tracking system. It helps users monitor food items, receive timely alerts, and take necessary actions before items expire.

Features
User registration and login
Add, update, and delete food items
Track expiry dates automatically
Dashboard alerts for expiring items
Email notifications for expiry alerts
Admin, Manufacturer, and User modules
Product management and order handling
Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Database: MySQL
Tools: PyCharm
Libraries: Flask-Mail, APScheduler

System Description

The system maintains a centralized database where all food items are stored. It calculates the remaining days before expiry and continuously monitors item status. When an item is near expiry, alerts are generated and sent to users through the dashboard and email notifications.

Modules

Admin Module:
Manages manufacturers, users, and expired food details

Manufacturer Module:
Adds products, manages inventory, and tracks expiry

User Module:
Registers, views products, places orders, and checks expiry details

Installation
Install Python and required libraries
Set up MySQL database
Configure database connection in the project
Run the Flask application
